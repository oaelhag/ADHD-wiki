# ADHD Wiki: مرجع العائلة

مرجع عائلي غير ربحي يحوّل ملخصات كتب ADHD والتربية إلى موقع ثابت قابل للبحث.

## البنية
- `content/books/` ملخص كل كتاب في ملف Markdown واحد (بلا أي بيانات شخصية).
- `content/meta/` تصنيف المستفيدين والأدوات لكل كتاب.
- `content/concepts.json` فهرس المفاهيم.
- `build.mjs` يحوّل المحتوى إلى `docs/data.json`.
- `docs/` الموقع نفسه (HTML وCSS وJS بلا خادم). منه يُنشر GitHub Pages.

## التشغيل محليًا
```
npm install
npm run build
cd docs && python3 -m http.server 8000
```

## إضافة كتاب
1. أضف ملف الملخص إلى `content/books/` بالقالب نفسه (راجع `brown-smart-but-stuck.md`).
2. أضف ملف التصنيف في `content/meta/` بالاسم نفسه.
3. شغّل `npm run build`.

## قواعد
- قبل أي commit: احذف قسم «ما يخص حالتي» ولا ترفع ملفات المصفوفة أو التقارير الشخصية. تاريخ git لا يُمحى.
- لا تشخيص ولا جرعات ولا توصية دوائية.
- الصياغة بكلمات المعدّ، بلا نصوص طويلة من الكتب.
- الموقع غير مفهرس (`noindex` و`robots.txt`) لكن الرابط ليس حماية. من يملكه يفتحه.
